\section{Alcance del servicio propuesto}

Deep Skill Academy S.A.C. dictará el curso ``Programación y Análisis de Datos con IA Generativa para Ingeniería y Ciencias'' conforme a la estructura definida en los términos de referencia:

\begin{itemize}[leftmargin=1.5em]
  \item \textbf{Modalidad:} online (videoconferencia en vivo).
  \item \textbf{Estructura:} 4 módulos, 8 sesiones de 2 horas (16 horas totales).
  \item \textbf{Participantes:} 30 alumnos (15 de la Escuela Profesional de Metalurgia y 15 de la Escuela Profesional de Minas).
  \item \textbf{Tecnologías:} Python, pandas, Jupyter Notebooks, terminal/línea de comandos, VS Code, Git/GitHub, Claude Code y/o Codex como eje de IA agéntica, Miro, Google Drive, Google Meet o Zoom.
  \item \textbf{Sesiones:}
  \begin{enumerate}[leftmargin=2.5em, nosep]
    \item ¿Qué es realmente un LLM?
    \item Del chat al agente: contexto, RAG, tools y agentes.
    \item Cultura de cómputo: sistema operativo, archivos y terminal.
    \item Git y tu primer agente en un proyecto real.
    \item Programación dirigida por IA: fundamentos con rigor.
    \item Flujo de trabajo agéntico: planear, depurar y verificar.
    \item Análisis de datos con IA: del dato al insight.
    \item Proyecto integrador de ingeniería/ciencias.
  \end{enumerate}
  \item \textbf{Certificación:} entrega de certificados digitales a los participantes que aprueben el curso.
  \item \textbf{Plazo de ejecución:} 45 días calendario, contabilizados a partir del día siguiente de notificada la orden de servicio.
\end{itemize}
